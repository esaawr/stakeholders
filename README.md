# BSA 01 — Анализ заинтересованных сторон (Stakeholder Analysis)

Учебный проект по дисциплине «Бизнес-системный анализ» (BSA).  
В рамках проекта выполнены задания по выявлению, классификации и анализу заинтересованных сторон (стейкхолдеров) для двух предметных областей: **сеть барбершопов (BRB)** и **служба доставки заказов (DEL)**.

---

### Exercise 01 — Построение луковичной диаграммы
- Определены категории (слои) стейкхолдеров относительно взаимодействия с системой:
  - **Создают систему** (команда разработки)
  - **Конечные пользователи** (курьер, диспетчер, оператор, администратор, клиент)
  - **Взаимодействующие стороны** (бухгалтерия)
  - **Затрагиваемые внешние стороны** (поставщики, регуляторы)
  - **Не общаются с системой** (заказчик, руководство)
- Построена луковичная диаграмма с указанием слоёв и стейкхолдеров.
- Дополнительно указаны стейкхолдеры, не данные в условии, но встречающиеся в жизни (сотрудники регулятора, сотрудники санэпиднадзора, служба сопровождения).

**Файлы:**
- `ex01_BRB_onion.*` (изображение)
- `ex01_DEL_onion.*` (изображение)

**Пример луковичной диаграммы (DEL):**

![Луковичная диаграмма DEL](ex01_DEL_onion.png)

> *Слои (от центра к периферии):*
> 1. **Создают систему** — команда разработки, администратор системы, служба сопровождения.
> 2. **Конечные пользователи** — курьер, диспетчер, оператор, администратор, клиент.
> 3. **Взаимодействующие стороны** — бухгалтерия.
> 4. **Затрагиваемые внешние стороны** — поставщики, регуляторы (санэпиднадзор).
> 5. **Не общаются с системой** — компания студентов (заказчик), руководство.

### Exercise 02 — Интересы, потребности, проблемы заинтересованных сторон
- Для каждого стейкхолдера выписаны:
  - **Интересы** — что важно для стейкхолдера.
  - **Потребности** — что система должна предоставить.
  - **Проблемы** — с какими трудностями сталкивается стейкхолдер.
- Данные структурированы в табличном виде.

**Файлы:**
- `ex02_BRB_needs.xlsx`
- `ex02_DEL_needs.xlsx`

**Пример (DEL, фрагмент):**

| Идентификация | Стейкхолдер | Интересы | Потребности | Проблемы |
|---|---|---|---|---|
| st00200 | Курьер | Получать достаточное количество заказов | Удобное мобильное приложение для просмотра и выбора заказов | Неудобно получать и отслеживать заказы через звонки |
| | | Легко и быстро выполнять доставки | Понятный интерфейс для бронирования и завершения заказов | Путаница с адресами и статусами заказов |
| | | Получать понятный и честный расчет оплаты | Личный кабинет с прозрачным расчетом оплаты | Неясно, сколько заработал |

### Exercise 03 — Наполнение глоссария

  - Роль в проекте
  - Каталог заинтересованных сторон
  - Регуляторы
  - Интегрируемая система
- Указаны определения, источники и даты добавления.

**Файлы:**
- `ex03_BRB_glossary.xlsx`
- `ex03_DEL_glossary.xlsx`
